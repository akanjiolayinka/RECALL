# Test data

Synthetic files for developing and demonstrating Recall. **Everything here is
invented** — no real people, documents or receipts. Never add real personal
files to this folder.

| File | What it tests |
| --- | --- |
| `pdf/Project Proposal - Riverside Community Garden.pdf` | Multi-page PDF; the budget is on page 3 |
| `pdf/Tenancy Agreement - Flat 4B.pdf` | Deposit and notice terms ("moving out" without those words) |
| `pdf/Scanned letter (no text layer).pdf` | A PDF with no text, like a scan — must be reported, not faked |
| `documents/Q3 Marketing Plan.docx` | Word text plus title/author metadata |
| `notes/Moving out checklist.md` | Markdown, title from the first heading |
| `notes/Meeting notes 2026-05-02.txt` | Plain text |
| `notes/Shopping list (UTF-16).txt` | UTF-16 text, as saved by older Windows Notepad ("Unicode") |
| `images/Headphones receipt.png` | An image: found by file name now; its text needs OCR |

To use it, add this `test-data` folder in Recall's **Library**.

The files are generated by `scripts/generate_test_data.py` (instructions at
the top of that script) and committed, so you don't need to run it.
